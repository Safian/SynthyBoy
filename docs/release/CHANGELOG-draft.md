# SynthyBoy - MPC Release Change Log (Draft)

SynthyBoy for the MPC is a synthesizer plugin (VST2) for standalone Akai MPC hardware, packaged as `Safian - VST - SynthyBoy` with a 32-bit ARMv7 and a 64-bit AArch64 build; it was tried by its author on the MPC Key 61 and the MPC XL only (docs/MPC.md#package-layout, docs/MPC.md#overlay-experimental).
It runs the project's own sound engine with a quality profile per device: the MPC XL plays 16 voices, up to 16 unison voices and all effects, the MPC Key 61 plays 8 voices, at most 3 unison voices and skips five effects (docs/MPC.md#quality-profile-per-device).
On the compact Play page, the MPC skin provides the selectors and dials. SynthyBoy draws the oscillator, envelope and LFO curves on its display overlay. The hardware Q-Link knobs follow the active page (docs/MPC.md#q-proxies-and-the-display-pages-overlay-build).
The instrument has 184 factory presets, 72 factory wavetables in six categories, 3 oscillators (wavetable, sample, granular, spectral, multisample), a sub oscillator and a noise source, 27 filter models in 12 styles, 6 envelopes, 10 LFOs and 4 random LFOs, a 64-slot modulation matrix and 13 effect types plus 3 band splitters (docs/params.json, docs/MPC.md#filter-ui, docs/MPC.md#mod-matrix-and-macros, docs/release/WAVETABLE-PACK.md).
The same codebase also builds the desktop plugin (VST3, CLAP, Audio Unit); this change log covers the MPC release only (README.md#synthyboy).

## State of the MPC Build

### Sound Engine
- **Engine codebase**: The MPC build runs SynthyBoy's own engine (`core/engine-own`), an original C++17 DSP codebase completely free of JUCE and isolated from GPL Vital source code (docs/ARCHITECTURE.md#22-licence-hygiene, core/engine-own/README.md).
- **Quality profile per device**: the shell picks the engine's quality once per process from the device name: MPC XL `high,voices=16,control=economy` (16 voices, unison up to 16, all effects, warps 4x oversampled, full-rate spectral morph, exact maths), MPC Key 61 and any unknown device `low` (8 voices, at most 3 unison voices, 2x warps, five effects bypassed); presets and projects store nothing of the profile, so they move between devices unchanged (`shell-mpc/device_profile.h`, docs/MPC.md#quality-profile-per-device, docs/MPC.md#projects-move-between-devices-unchanged).
- **Oscillator models**: Features 3 main oscillators supporting Wavetable (with spectral morph and two warp slots, each with its own phase), Sample, Granular, Spectral, and Multisample modes, plus a dedicated Sub oscillator (6 shapes) and Noise source (9 noise types / sample) (docs/MPC.md#oscillator-ui, docs/ARCHITECTURE.md#32-oscillators, d90e1a0a, 42682c52).
- **Oscillator options**: Improved functionality with fixed pitch (while tracking is off), transpose snap with 12-note mask, key fold, key warp, phase memory (all voices, contiguous, per voice), and phase legato; includes sustain pedal, All Notes Off, and All Sound Off behaviour (docs/MPC.md#every-oscillator-parameter-has-a-control, docs/MPC.md#led-controls-and-the-transpose-snap-editor).
- **Filter collection**: Includes 2 main filters and an effect filter with 27 models in 12 styles per model (Analog, Dirty, Ladder, Digital, Diode, Formant, Comb with 6 styles, Phaser, Scream, etc.; docs/params.json `filter1.model`, `filter1.style`) and parallel, series 1 to 2, series 2 to 1 routing (`filter.routing`) (docs/params.json, docs/MPC.md#filter-ui, 69460e77, a1166d2c).
- **Modulator complement**: Provides 6 envelopes with adjustable curvature parameters, 10 LFOs with custom shape support, and 4 random LFOs (docs/MPC.md#lfo-pictures, docs/MPC.md#envelope-ui, 82917444, c8544168).
- **Modulation matrix**: A 64-slot matrix routing 57 internal modulation sources with bipolar depth, polarity, and bypass controls (docs/MPC.md#mod-matrix-and-macros, 1eafdf37, 6b191edb).
- **Approximations of the profile low (Key 61)**: Warped oscillators run 2x oversampled with a 32-tap Kaiser decimator; spectral morph cycles update every 512 samples; tanh uses a [7/6] Padé rational function (< 1e-4 error); sin/cos use a 1024-entry interpolated table; exp/pow/log2 use polynomial forms; filter coefficient calculations interpolate across 8-sample sub-blocks; inactive modulators step every 4th control period; voice stealing applies a 3 ms kill fade ramp; the XL profile keeps only the last group of these, the control economy (docs/MPC.md#sound-differences-at-tier-low, 4cd77ce, bc0f3ce, e3abe08, 178316e, e596f94, 91f2d75).
- **Bypassed vs active effects**: Profile low bypasses reverb, flanger, Hyper/Dimension, Bode frequency shifter, and Convolve; active effects are chorus, compressor, delay, distortion, EQ, effect filter, and phaser; the XL profile runs all of them; the reverb's FORCE ON value lets it run anyway (docs/MPC.md#sound-differences-at-tier-low, docs/MPC.md#quality-profile-per-device).
- **Level makeup for bypassed effects**: Added level compensation for device profiles (e.g. Key 61) when bypassing effects, ensuring consistent loudness compared to the full engine profile (XL) (docs/release/TIER-LEVEL-COMPENSATION.md).
- **Oscillator performance**: Faster content oscillator implementation reduces overall CPU load (docs/release/CPU-REVIEW-CONTENT.md).
- **Spectral voice start**: Refined voice start logic in Spectral mode; first 12 ms differ slightly from the previous version (docs/release/AUDIBLE-CHANGES-ROUND-13.md).
- **List pop-up improvements**: UI list pop-ups now dynamically adjust to fit their content rows (docs/ui-components/list-popup.md).
- **Point modulation**: Modulation points are now stored within saved LFO shapes (docs/ui-design/lfo-editor-capabilities.md).
- **Modulation page Q knobs**: Added Q knobs for better control on the point modulation page (docs/MPC.md#q-proxies-and-the-display-pages).
- **Filter CPU optimization**: Pair kernels implemented for filter stages, optimizing performance (docs/MPC.md#sound-differences-at-tier-low).
- **Engine cost on the XL**: measured on the MPC XL on 2026-11-17 the dearest factory preset with 16 held notes stays inside the block under the XL profile; on the Key 61 the dearest presets under `low` are at or over the block, so that device has no room for a higher step (docs/MPC.md#quality-profile-per-device, docs/MPC.md#observed-on-the-device).
- **SIMD determinism**: ARM NEON vector loops (`core/engine-own/dsp/simd.h`) compiled with `-fp-contract=off` produce bit-identical sample output to scalar code across all 112 factory presets on ARMv7 and AArch64 Linux (docs/MPC.md#mpc-xl-64-bit-aarch64).
- **Pad pressure integration**: Polyphonic aftertouch (MIDI 0xA0) adds a per-voice cutoff offset to Filter 1 (up to 36 semitones, smoothed with a 12 ms one-pole filter), leaving matrix presets without duplicate effects (docs/MPC.md#pad-pressure, 45_pad_pressure.py, test_own_pad_pressure.cpp).
- **Lazy wavetable loading**: Built-in wavetables are constructed at most once in the background by a low-priority thread rather than freezing audio on preset changes or parameter sweeps; live table changes hold and play the current table until the new one finishes without audible dropouts or default fallbacks, indicated by an amber loading bar at the top of the display (docs/MPC.md#wavetables-how-a-table-gets-to-the-audio-thread, docs/MPC.md#loading-mark, 67628616).

### Presets
- **Factory content**: 184 factory presets listed in groups (docs/release/SOUND-SET-CATEGORIES.md) with ordered PRESET selector, includes factory content pack (docs/user-guide/factory-content.md) and factory sounds chapter (factory-sounds.md) in CC0 ContentPack format under `content/presets/` generated deterministically via `scripts/gen-factory-presets.py` (README.md#factory-content, docs/MPC.md#build, 0a46744f).
- **Factory wavetable pack**: Includes 72 factory wavetables (18.5 MB) organized across six categories (Analog, Digital, Metallic, Noise, Spectral, Vocal, with 12 tables each), synthesized from scratch under CC0; each table provides 64 single-cycle frames (2048 samples per frame) normalized to an even 0.35 RMS per frame with a 0.9 peak limit for smooth scanning sweeps (docs/release/WAVETABLE-PACK.md, docs/user-guide/factory-content.md#2-factory-wavetables, 43304c10, 0e9e4dd9).
- **State format**: Each preset is a `synthyboy-preset` file (format 1) holding a `synthyboy-state` version 4 with all 2637 parameter keys explicit, the same count and state version as the parameter table (`content/presets/Bass/scream_filter_bass.sbpreset`, docs/params.json `count` and `stateVersion`; 038b6538 introduced state v3, since raised).
- **State version 5**: the writer's state format is version 5, which stores the grid of a drawn LFO shape (GRID X and GRID Y) with the shape; a document of version 4 or older loads with the grid inferred from the points, and a reader of version 4 still reads a version 5 document (docs/MPC.md#f2-the-grid-is-stored-with-the-lfo-state-version-5).
- **Pad pressure in the presets**: 65 factory presets (all 30 pads, 24 of 26 leads, 8 keys, 2 FX, 1 bass; 66 with pressure routes) carry a route from Poly Aftertouch to Filter 1 Cutoff in their own matrix; the plugin-wide pad-pressure switch is off by default at 35 percent (docs/MPC.md#pad-pressure).
- **Perceptual loudness levelling**: All 160 factory presets are calibrated using an ITU-R BS.1770 K-weighted perceptual loudness standard across category-specific playing gestures (loudest 100 ms window), balancing aggressive distorted patches, sub basses, and slowly opening pads; seven presets received octave register corrections via master transpose, and Fast Arp Bass was rebuilt as a real tempo-synced arpeggio (docs/release/SOUND-FIXES-1.md, c7ef2d29, 53dd6ff2).
- **Preset loudness and output limiter**: Factory presets have been calibrated to sit at the exact same loudness as the stock Akai instruments, so switching between SynthyBoy and built-in MPC plugins no longer causes volume jumps. A shared look-ahead limiter (-0.5 dBFS ceiling, LIMIT toggle on Master page, enabled by default) idles transparently during normal playing and acts as a safety guard against over-0 dB peaks on dense chords or aggressive attacks, eliminating hard clipping without altering instrument dynamics (docs/release/LEVELLING-STOCK-2026-11-19.md, docs/MPC.md#output-level).
- **Showcase patches**: Includes 12 specialized showcase presets demonstrating version 3 DSP features, including Scream Filter Bass, Custom Shape Wobble, MPE Pressure Lead, Diffusor Cloud Pad, and Bode Shifter Drone (README.md#factory-content, 0a46744f).
- **Preset browsing**: 185 programs (Init + 184 factory presets) are exposed directly as VST2 programs in the MPC preset browser (docs/MPC.md#install-on-the-mpc).
- **Project persistence**: Presets and state are saved in MPC project files via VST chunk format with "chunk wins" protection against post-restore host program resets (docs/MPC.md#project-save-and-reload, play_restore_host.cpp).
- **Updated factory preset levels.** Existing MPC projects restore the instrument settings saved with the project. To use the updated factory level, save a copy of any edited sound you want to keep, then reload its factory preset ([factory level notes](OUTPUT-LEVEL.md)).

### MPC Plugin Shell
- **Binary bundle**: Deployed in folder `Safian - VST - SynthyBoy` containing 32-bit ARMv7 `synthyboy-arm32.so` and 64-bit AArch64 `synthyboy-arm64.so` stripped VST2 binaries (docs/MPC.md#build, docs/MPC.md#package-layout).
- **Linkage compliance**: Links exclusively against system libc, libm, libdl, libpthread, and dynamic loader; no dynamic libstdc++; exports strictly `VSTPluginMain` (docs/MPC.md#build).
- **Crash isolation**: Wraps plugin initialization and all dispatcher calls in `catch (...)` handlers to prevent unhandled exceptions from terminating the host process (docs/MPC.md#observed-on-the-device).
- **Display thread**: One display thread per plugin instance (normal priority: `SCHED_OTHER`, nice 0) reports parameter changes to the host with `audioMasterAutomate` and tells it to re-read names with `audioMasterUpdateDisplay`; the audio thread does not call the host (docs/MPC.md#known-host-behaviour, thread_policy.h, 23e25c2d).

- **Output gain and limiter.** SynthyBoy starts at unity gain (0 dB). The output limiter is off, so the output stage adds zero latency. Turn on LIMIT on the Master page to cap peaks at −0.5 dBFS. Your MPC project saves the LIMIT setting. ([Output limiter](../MPC.md#output-limiter))

### Drawn UI Page by Page (Overlay Build)
- **Multi-plane display rendering**: Renders on an independent hardware overlay plane (found at run time; the measurements used plane 38 on the Key 61 and plane 46 on the XL) positioned above host UI with runtime CRTC and plane discovery (docs/MPC.md#overlay-experimental, discovery.h).
- **GPU helper daemon**: Out-of-process rendering daemon (`synthyboy-overlay-gpu-arm32` / `arm64`) using OpenGL ES 2 and Panfrost drivers over UNIX seqpacket socket and memfd, falling back automatically to CPU rendering (docs/MPC.md#gpu-drawing-in-a-helper-process, scene.h, gpu_overlay.h).
- **Controls.** The MPC skin provides native selectors, buttons and parameter controls. The overlay draws the live curves and provides the interactive canvases and fallback controls. See the control assignments for [Play](../ui-map/play.md) and [LFO](../ui-map/lfo.md).
- **Play.** The oscillator, envelope and LFO panels share one performance page. Each has a native source menu and an Expand button beside its graph. Expanded OSC, ENV and LFO/RND editors reuse the same MPC control groups as their standalone tabs. A disabled oscillator keeps POWER, its selector and CLOSE available. Native CLOSE returns to the compact view and restores its Q-Link targets (Mac VST checks: `shell-mpc/tests/play_host.cpp`). See [Play controls](../ui-map/play.md).
- **Master page (`MasterUi`)**: Dual-sided view covering Main section (Output, Pitch bend, Voice allocation, Glide, the PAD PRESS switch and its amount) and Tuning/MPE section (microtonal scale selector with dark touch keyboard, tuning systems, MPE parameters), re-flowed so that the Q groups read in order, with poly-cell active voice meter (docs/MPC.md#master-and-voice, d700b6f1, a5126580, c72b9f37).
- **Master strip switches**: Positioned below the output Q-Link knobs on the Master page, a dedicated touch strip provides three instant LED switches: LIMIT (engages the look-ahead output peak limiter to prevent clipping, saved in project chunk), NO SMOOTHING (bypasses parameter interpolation for immediate stepping, ideal for hard rhythmic gating, saved in preset), and OVERSAMPLE 4X (engages 4x oversampling for pristine wavetable highs without warps) (docs/MPC.md#text-that-did-not-fit-content-names-missing-content-master-quality-2026-11-17-from-the-layout-lint-and-the-renders, docs/user-guide/SynthyBoy-MPC-User-Guide.md#512-master, 80850691, ef1ef5bd).
- **Filter pages (Filter 1 & 2, `FilterUi`)**: Visualizes real-time dB/log-frequency response curve (`FilterResponse`), interactive cutoff/resonance drag handles, formant pad, model lists, style steppers per model, Comb filter's six styles, the CURVES list (F1, F2, F1+F2) and the ROUTING LED list, and serial/parallel dual-curve combinations clipped cleanly at -48 dB display boundary (docs/MPC.md#filter-ui, docs/MPC.md#voice-and-filter-led-pages, a1166d2c).
- **Oscillator pages (Osc A, Osc B, Osc C, Sub, Noise, `OscPageUi`)**: Dedicated full-screen pages replacing old picture views, layout reflowed to ensure >= 240 px display height, 2D wavetable cycle display with bipolar fill and unison hairlines, five type keys (WAVE, MULTI, SAMPLE, GRAIN, SPEC), vertical tuning column, WARP 1 and WARP 2 with a phase each, ContentBrowser, and "content missing: <name>" warnings on the oscillator display and the Convolve page, plus a thin amber loading bar while wavetables are prepared (docs/MPC.md#oscillator-ui, d557a512, 0a618f27, b78d9de8).
- **Noise oscillator page (`OscPageUi` - Noise)**: Reflowed into single-row blocks at maximum row height, dedicating the freed vertical room to the display. Features two adaptive layouts: with generated noise (`KIND = Noise`), the display spans the full width over side-by-side TUNE (left, with width adjusted so KIND reaches minimum width) and NOISE (right) blocks; with sampled noise (`KIND = Sample`), the display sits on the left with a vertical TUNE column beside it, and SOURCE and PLAYBACK blocks along the bottom row (docs/MPC.md#layout-of-the-noise-page-2026-11-18, bf6c4223, 2952f44e).
- **Wavetable browser and user tables**: A two-level browser opens directly from the table selector on the Play and oscillator pages, navigating built-in categories (Basic, Morph), installed content packs, and user folders on SD cards, USB drives, or the plugin Content folder (`SynthyBoy/Wavetables/<Category>/`) without requiring rescans or restarts (docs/MPC.md#the-wavetable-browser-categories-packs-the-players-own-files, docs/user-guide/factory-content.md#loading-wavetables-wavetable-oscillator-the-wavetable-browser, 18d19d6b, 308dd896). It loads standard 2048-sample mono WAV files (16/24/32-bit int, 32-bit float, up to 256 frames or 16 MB) as well as single-cycle waveforms (16..4096 samples stretched to 2048) and files with frame metadata chunks (docs/MPC.md#which-wav-files-the-engine-accepts, 16df7e89). While playing any file table, the selector arrows and Q-Link knob step sequentially through every table in the current category without wrapping, allowing fast category auditioning (docs/MPC.md#the-selector-and-the-stepping, 18d19d6b, 308dd896).
- **LFO shape editor (`LfoUi`, `ShapeCanvas`, `PointModPage`)**: Full-screen vector editor for custom LFO shapes (2 to 128 points, 32 undo levels) opens from the standard LFO graph’s Expand button. Features seven touch tools: POINT (adds/drags points and segment curvature, double tap to delete point or reset curve, long-press delete), FLAT (horizontal step drawing with interpolated drag across columns), RAMP+ and RAMP- (rising/falling saw teeth drawing), SELECT (bounding rectangle, multi-point selection, and relative group dragging), SOFT (linear falloff brush with rainbow weight feedback), and BEND (adjusts all curves simultaneously) (docs/user-guide/SynthyBoy-MPC-User-Guide.md#59-lfos-and-the-drawn-shape-editor, 1434acc4, b70dd4af). Includes an interactive START / LOOP marker with a drag handle bound to the engine PHASE parameter and trigger MODE (continuous START offset in Retrigger/Envelope, snapping LOOP bookmark in Sustain/Loop modes); a dedicated Point modulation page (MOD) routing any of the 57 modulation sources to point TIME, LEVEL, or CURVE with live range bars on canvas; a two-level SHAPES menu for factory shapes and user shapes saved to SD card or USB storage (`SynthyBoy/LFO Shapes/<name>.lfoshape.json`) with replace/rename/delete; and a MORE menu with EDIT actions (Select All, Horizontal/Vertical Flip, Shift Left/Right with wrap-around, Reset Curves, Clear Loop), GRID presets (4x4 to 32x32, Halve, Double, Follow Points), and cross-module COPY actions (to other LFOs, convert single cycle from Osc A/B/C to LFO points, or export LFO shape as a 2048-sample WAV wavetable to Osc A/B/C) (docs/MPC.md#lfo-page-and-the-lfo-editor-overlay-build, 1434acc4, f9f3c1a0).
- **Middle truncation for long content names (`content_name.h`)**: Long preset, wavetable, sample, and missing-content file names that exceed available display bounds or internal pen buffers (96 bytes) are cleanly truncated once in their middle with an ellipsis (`middleFit`), preserving both the beginning and distinguishing end of the name (e.g. "drum loop 1…20 bpm"), ensuring consistent single-cut rendering across Steppers, missing-content warnings, and effect notices without repeated tail-clipping (docs/MPC.md#one-cut-for-a-content-name-2026-11-18, bc3a05b1, 3828e026).
- **Editor and UI fixes**: Renaming a saved LFO shape with a case-only change on case-insensitive file systems (FAT/exFAT SD cards, macOS) preserves the shape file without deletion (88382e77); turning a Q-Link knob in the LFO editor that produces no value change leaves no empty undo state (88382e77); shifting an LFO shape across grid columns keeps the loop point at the cycle start when the cut lands on an existing point (b8831b4a); editing a shape in the LFO editor preserves existing point modulations (f9f3c1a0); and the START / LOOP marker caption sits cleanly below its drag handle, avoiding overlap with the point counter (c553d1ba, e5decad4).

### Hardware Control
- **16 Q-Link knobs**: 16 proxy parameters (`Q 1`..`Q 16`) mapped to page controls in reading order, wrapping around, with slots 1-4 mapped to active Q group and slots 5-16 to the next groups; on the XL the chips 5..16 show on the idle groups, on the Key 61 the chips show 1..4 relative to the bank (docs/MPC.md#q-proxies-and-the-display-pages-overlay-build, docs/MPC.md#chips-on-the-screen, 7da8db33).
- **Device detection**: Automatically detects 4 physical knobs on Key 61 vs 16 knobs on MPC XL via `/proc/device-tree/model` (docs/MPC.md#chips-on-the-screen, ecb776ad). On Key 61, the Q-Link button cycles the four banks (`Bank Direction "Row"`) (docs/MPC.md#measured-on-the-key-61, f2e133c7).
- **Relative travel for stepped parameters**: Toggles, lists, and integer steppers move one step per small turn (6 of the 128 increments of the knob, set from a trial on the XL; at most four steps per host write, the ends of a list stop) instead of being set by the knob's absolute position (docs/MPC.md#stepped-targets-are-driven-relatively, 01ac74a3).
- **Host Q-Link panel handling**: Dynamic optical keying detects host Q-Link Status popup and clips overlay rendering along left edge, allowing host display to show through smoothly; with the host option switched off the plugin reads it and the key is off (docs/MPC.md#the-hosts-q-link-status-pop-up, 23e25c2d, da5eec7d).
- **Standby dim**: the plugin recognises the host's standby dim (backlight drop and dimmed markers), darkens its picture with it and swallows the waking touch; the XL's dim values are not measured (docs/MPC.md#standby-dim-overlay-build, 5c470640).
- **USB mouse support**: Connects to `/dev/input/event*` devices without exclusive grab; left click generates touch down/up and a drag turns a knob relatively (a click on the arc does not make the value jump), cursor position is determined from DRM atomic properties on host pointer plane, and the mouse wheel steps the control under the pointer by one Q-Link step per notch (docs/MPC.md#the-mouse-path, b9e331f0, 370c3895).
- **Plane order under the host's pointer**: Where the driver has a mutable `zpos` (the XL), the overlay puts its plane directly above the host's picture and below the host's pointer plane so that the pointer stays visible; the XL's plane table was measured, the rule itself is not verified on a device (docs/MPC.md#overlay-experimental, 397c0654).
- **Modulation control**: Interactive knob modulation chips allow depth dragging on touch screen; long-press opens ModulationsPage for routing. TARGETS and the long-press editor show six routes per page. Use ADD and REMOVE to change the routing. See [modulation controls](../ui-components/modulations-page.md).

### Developer Tools
- **Wavetable lab**: Python command-line tooling (`scripts/wavetable-lab.py`) generates, scores, auditions, and promotes wavetable candidates from procedural JSON grammar recipes into factory or add-on content packs (docs/CONTENT-PACKS.md#the-wavetable-lab, db8d0b3d).

### Known Problems and Limits
- **Denormal warning in SDK simulator**: `host_sim` reports 32 denormal samples during parameter sweeps with Vital engine due to simulator threshold discrepancy with IEEE 754; harmless on hardware (docs/MPC.md#denormal-warning-in-host-simulator).
- **Key 61 Q-Link panel flicker**: Rapid knob turning previously caused reference drops and flickering on Key 61; the key was reworked in code and reads the host option from `MPC.settings`, but the flicker is a known open bug: the rework is verified by host tests only, not on the device; the user-side way around it is to switch the host's pop-up off (docs/MPC.md#overlay-pages-overlay-build, b0b8cc69, 909).
- **Mouse pointer on the XL**: the zpos rule and the pointer hot spot of the XL are not measured on a device (only the Key 61 has a measured hot spot in `mouse_router.h`) (docs/MPC.md#overlay-experimental, 597, 891).
- **Single overlay plane**: Multi-instance environments support overlay display for only one active instance at a time; instances beyond the 16th receive no overlay slot (docs/MPC.md#several-instances).
- **Pad pressure limitation**: Full Level hardware button disables polyphonic aftertouch entirely (docs/MPC.md#full-level-must-be-off).
- **Heavy patch performance**: Synthetic heavy patches (3 osc, 2 filters, FX, 8 notes) exceed the 2.902 ms block deadline on MPC Key 61 (average 3.35 ms), and in the bench of 2026-11-17 the dearest factory presets (Diffusor Cloud Pad, Scream Filter Bass) sit at or over the block under profile low with eight held notes; the XL profile stays inside the block (docs/MPC.md#observed-on-the-device, docs/MPC.md#quality-profile-per-device).
- **Sample loader format constraints**: ContentBrowser supports WAV and SFZ files only; FLAC is unsupported, and SFZ files with relative directory traversal (`..`) are rejected (docs/MPC.md#the-content-browser).
