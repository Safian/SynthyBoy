How this file is made. Part A is written by hand: every entry names its source as `file:line` (the line contains one of the search patterns) or a commit, and its state. Fixed bugs are not listed. Parts B and C are generated by `scripts/gen-open-questions.py`; `scripts/tests/test_docs_release.py` regenerates them and fails when the file is stale.

Search that Part B runs (case-insensitive, per line):
