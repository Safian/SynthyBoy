# Natív OSC komponensek

Az elfogadott komponensek, változataik és képeik a [generált képes katalógusban](kepes-katalogus.html) találhatók. A katalógus a komponensek saját `catalog.json` fájljait, valamint a közös szín- és méretfájlt használja.

Az OSC kezelői a közös Pan, Level, Button, Selector és Tune komponensek példányai. Az összevont változatok nem külön komponensek.
