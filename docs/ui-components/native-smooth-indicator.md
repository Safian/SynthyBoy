# Smooth a képernyőn

A SMOOTH két meglévő komponens képernyőn összeállított használata:

- [Level](../../components/native/level/level.py): a simítási idő potija és értéke.
- [ActiveText](active-text.md): a SMOOTH felirat ON/OFF állapota és kapcsolása.

Nincs külön Smooth komponens vagy katalógusvariáns. A két elem képei a saját komponensük alatt szerepelnek a [képes katalógusban](kepes-katalogus.html).

Az elhelyezés, az idő- és állapotparaméter kötése, valamint az OFF írásvédelme a képernyő összeállításának feladata. A meglévő Smooth összeállító és kötési függvények nem jelentenek új önálló vizuális komponenst.
