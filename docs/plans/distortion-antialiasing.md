### 1.2 How big it is (numbers)

* **Sound: unmeasured.** Nothing in the repository measures the aliasing of the distortion or of a warp. The audits are code reading, the verification marks rank 1 `CONFIRMED` for the code and lists "measurement still needed: none" although no level in dB exists anywhere. The only related measurements: (i) the Filter-warp test keeps an inharmonic floor below -95 dB relative (`core/tests/test_own_osc_types.cpp:912-975`; its helper `inharmonicFloorDb`, 866-908, uses a Blackman window and excludes +-1 % or 40 bins around each harmonic, local to that file); (ii) `tools/own-oracle/own_oracle.h:193-205` `inharmonicDb` (Hann window, +-12 % of the harmonic spacing), used only by the oracle tools that need engine-vital; (iii) **Sync 35 % at note 60: the render at 2x differs from the render at 4x by -25 dB** ("the rest is the aliasing (measured -25 dB)"), bound `-15 dB` (`core/tests/test_own_profile.cpp:36-41,288-289`). Number (iii) is the only measured size of the warp problem: it says the 2x stream is not alias free for hard sync at a low note, and it says nothing about notes above 60. Section 2 builds the measurement that gives the others.
* **Sound, by arithmetic from the code (what is certain without a measurement).** A memoryless law applied at fs creates harmonics at every multiple of f0; the ones above 22 050 Hz fold back. Example, hard clip (type 1) of a sine of peak 0.5 at +18 dB: `g = 10^(18/20) = 7.943`, `v` peak `3.97`, so the output is a clipped sine whose edge between -1 and +1 takes `2 * asin (1 / 3.97) = 0.509 rad` = 0.081 of a cycle; at f0 = 1000.6 Hz the harmonics 23 and above (`22050 / 1000.6 = 22.04`) alias: with an edge that fast their amplitude is still about `4 / (pi h)` of a square wave (HYPOTHESIS for the dB value; the decision is the measurement M-A of section 2).
* **CPU today.** Distortion: 256 shape evaluations per block (128 frames x 2 channels, `fx_effects.h:692-701`). The only measured cost is `1.3 %` of a block for Triple Fold Reese, taken before the constants were hoisted (`docs/release/CPU-REVIEW-FILTER-FX.md:349`; 1.3 % = 37.7 us / 256 = 147 ns per sample and channel on a 1.608 GHz core = 236 cycles, an upper bound for today's code because it still contained `pow10` and a division per sample). The cost of the warps: not measured by any preset (no preset uses a nonlinear warp); the audit's count is 6144 scalar libm calls per block for Linear Fold or Soft Sat at tier low (`2 * 128 * 24`: 2x oversampling, 128 frames, 8 voices x 3 unison lanes), which is arithmetic, not time.
* **The Key 61 budget these changes must live in.** Basic patch 8 notes: mean block 0.535 ms = 18.4 % of a block; each note costs about 0.070 ms = 2.4 % (`docs/MPC.md:68-71`); mean over the 112 presets 36.4 %, worst presets 80 to 100 % at the 99th percentile, Diffusor Cloud Pad 100.7 % (`docs/MPC.md:321`, quoted by `docs/plans/perf-measurement.md`). So every added percent has to be earned, and a change that is paid only by a patch that uses the feature is preferred.

### 1.3 What the audit findings got wrong, what was already fixed

1. **Audit 2 rank 1: confirmed**, with corrections: the cited lines `fx_effects.h:675-734` are now `682-757`; the per-sample `pow` / `exp` it also mentions is fixed (1.1 A f); the audit's remedy "2x / 4x halfband IIR oversampling" is in conflict with the specification's zero latency for the distortion (1.1 A g): an IIR half-band has a frequency-dependent group delay of several samples that cannot be reported as an integer, and a linear-phase FIR half-band has a fixed delay that the spec says the distortion does not have. The remedy "1st-order ADAA for Hard Clip, Soft Clip, Linear Fold, Rectify, Diode" is zero latency and is the base of the chosen design (section 3).
2. **Audit 1 rank 4: confirmed as code, narrower than stated.** At tier low the factor is already `1.0` = the Nyquist of the 2x stream (`wt_osc.h:568,675`), so only the 4x path (XL, desktop, `warp=4x`) asks for 3.2. For a **linear** use of the table (no warp, Sync, Bend, Formant, FM) the harmonics between 2.0 and 3.2 fs fold into 0.8 to 2.0 fs of the 4x stream, which is the stopband of the decimator (`kDecimator4`, cutoff 0.105 cycles per sample of the 4x stream = 0.42 fs, Kaiser beta 7.5, 128 taps: transition about 0.34 to 0.50 fs by the Kaiser estimate `N = (A - 7.95) / (2.285 * d_omega)` with `A = 7.5 / 0.1102 + 8.7 = 76.8 dB`: `d_omega = 68.85 / (2.285 * 127) = 0.237 rad = 0.0378 cycles` = 0.151 fs); the spec states 3.2 as the behaviour (`02-oscillator.md:452`) and it has a reason (images land at 0.8 fs and above). It matters only where a **sample-domain nonlinearity** follows the table read inside the oversampled stream (Quantize, the 14 Dist warps), which mix those images into the audible band. Example from the code, note 96 (2092.97 Hz), bw 1: `ratio = 3.2 * 44100 / 2092.97 = 67.43`, `levelFor` takes the first level whose `maxHarmonics <= 67.43` = 64 harmonics (`core/engine-own/osc/wavetable_bank.cpp:233,255-263`, levels `1024, 512, 256, 181, 128, 91, 64, 45, 32, ...`), top harmonic `64 * 2092.97 = 133.95 kHz = 3.04 fs`, of which harmonics 43 to 64 (22 of them) lie above the 4x Nyquist `88.2 kHz`; with the factor 2.0: `ratio = 42.14`, level 32 harmonics, top `66.97 kHz = 1.52 fs`.

The libm calls are per oversampled sample; at tier low only the five named in 1.1 C e are libm, the others use `fastmath`. The library oscillators (1.1 C f) are a **worse** case than the one in the audit (host rate, no oversampling) and are not in the audit.

### M-A. The aliasing level of the distortion effect (new, task A1 and A2)

Signal: a **coherent** sine into `Distortion::process`, so that no window leakage is mistaken for aliasing. `fs = 44100`, `N = 65536`, bin `m = 1487`, `f0 = 1487 * 44100 / 65536 = 1000.6 Hz` (1487 is odd, so `gcd (m, N) = 1`). Folded components land at bins `(h m) mod N` or `N - ((h m) mod N)`; the distance of such a bin from the nearest multiple of `m` is `(j * N) mod m` or its complement, `65536 mod 1487 = 65536 - 44 * 1487 = 108` bins for the first fold, then 216, 324, 432, 540, 648, 756, ... : the first value that comes within 8 bins of a harmonic is `j = 55` (`55 * 108 = 5940 = 4 * 1487 - 8`), so with an exclusion of +-5 bins no alias line of the first 54 folds is mistaken for a harmonic and every harmonic is excluded.
Window: 4-term Blackman-Harris (side lobes -92 dB, main lobe +-4 bins), FFT of the last 65536 samples of a 81920-sample render (the first 16384 skipped for the DC blocker and the filter).
Quantity recorded, per type and per drive: `ALIAS_DB = 10 log10 (P_nonharmonic / P_harmonic)`: `P_harmonic` = power in the bins within +-5 of `h m`, `h * m < N / 2`; `P_nonharmonic` = power in all other bins from bin 6 (about 4 Hz) to `N / 2`. Reported also: `HARM_DB` (the power of the harmonics re the input power) so that a change that merely lowers all harmonics is seen.
Grid: types 0, 1, 2, 3, 6, 7, 8, 9, 10, 11 (and 12, 13 after batch C) x drive {0, +12, +24} dB x input peak 0.5; `filter_order` None, `mix` 100, `fast` false and true.
The same law applied inline in double precision to the same input (the "naive reference") is recorded next to it: it equals the effect's output today (the effect IS the naive law), so before any change `ALIAS_DB (effect) - ALIAS_DB (naive) = 0.000 dB` by construction, and that difference is what the later tests assert on.

### M-B. The aliasing level of a rendered note (new, task A2)

Signal: the engine renders one held note (`osc1.level 100`, `env1.attack 0`, `filter1.on 0`, `master.volume 0`, `osc1.random_phase 0`, unison 1, built-in Saw table `osc1.wavetable 1`, 1.5 s), the left channel, 65536 samples from 0.5 s on, the same window and the same `ALIAS_DB`, with the harmonic positions `h * f0` computed from the note's exact frequency (the oscillator's phase step is a 32-bit integer, error below 1e-9 relative), exclusion +-6 bins.
Grid: notes {60, 72, 84, 96, 100} x warps {Sync 35 %, Sync 15 %, Dist Hard Clip 50 %, Dist Linear Fold 50 %, Dist Rectify 50 %, Dist Soft Clip 50 %, Dist Zero Square 50 %, Quantize 50 %, none} x quality {tier low (2x, 32 taps), tier high (4x, 128 taps)}. 5 x 9 x 2 = 90 renders of 1.5 s.
Reference for the oscillator tests (no stored constants): the same oscillator with the fix switched off by a test-only tick field (task C0), so one binary gives both numbers and the test asserts on their difference.

## 3. Design options and the chosen design

### 3.0 The three techniques and what they do to a signal (derived, not measured)

* **First-order ADAA** (antiderivative anti-aliasing: Parker, Zavalishin, Le Bivic 2016; Bilbao, Esqueda, Parker, Valimaki 2017). For a nonlinearity `f` with antiderivative `F` (`F' = f`) the output is `y[n] = (F (v[n]) - F (v[n-1])) / (v[n] - v[n-1])`, and `f ((v[n] + v[n-1]) / 2)` when `abs (v[n] - v[n-1])` is below a threshold. That is the average of `f` over the straight line between two input samples, i.e. the naive output of the continuous nonlinearity, filtered by a box of one sample and then sampled. Consequences: (1) every spectral line above Nyquist is weighted by `sinc^2 (f / fs)` in power before it folds (zeros at `fs`, `2 fs`, ...); (2) the output is delayed by half a sample; (3) in a linear stretch of `f` it equals `(v[n] + v[n-1]) / 2`, a two-tap low pass `cos (pi f / fs)`. Latency in the sense of the spec (integer samples reported to the host): zero; the half sample is a property of the signal path.
* **Polyphase half-band oversampling** (2x or 4x; reference: de Soras, HIIR, 2005 for the IIR form; Kaiser-window FIR half-bands in any DSP text, the engine already builds Kaiser decimators, `core/engine-own/osc/wt_osc.h:84-112`). Run the law at `os * fs`, low-pass, decimate. Lines between `fs / 2` and `os * fs / 2` are not aliased at all, those above fold into a band of which only `1 / os` stays audible.
* **BLEP / BLAMP** (band-limited step / ramp: Brandt 2001; Valimaki, Pekonen, Nam 2012 for PolyBLEP; Esqueda, Valimaki, Bilbao 2016 for PolyBLAMP). A discontinuity of the signal (jump `J`) or of its slope (`dS`, per sample) at a known sub-sample instant is replaced by its band-limited version by adding a short residual to the 2 samples around it. Derived here for the 2-point polynomial form: with `d` in [0, 1) the time since the event measured at the first sample after it (in samples), the residual added to the sample after is `-(J / 2) (1 - d)^2` and to the sample before `+(J / 2) d^2` (step), `+dS (1 - d)^3 / 6` and `+dS d^3 / 6` (ramp). Check: for `J = 1`, `d -> 1` the sample before moves by `1/2` (the band-limited step passes through the midpoint) and the sample after by 0; the continuous residual `r (u) = (1 + u)^2 / 2` for `-1 < u < 0`, `-(1 - u)^2 / 2` for `0 <= u < 1` jumps by -1 at `u = 0`, cancelling the step, and its integral over `[-1, 1]` is `1/6 - 1/6 = 0` (the ramp residual `rho (u) = (1 + u)^3 / 6`, `(1 - u)^3 / 6` is its running integral, zero beyond `u = 1`, so a residual changes no mean level).

**Estimated alias suppression by these techniques (HYPOTHESIS; model: the power spectrum above Nyquist of a signal with edges falls as `A / f^2`, the folded power is spread evenly over the audible band; the decisions are the measurements M-A and M-B).**
Power that folds into the audible band `[0, fs / 2]`, in units of `A / fs`: at 1x all of `f > fs / 2`: `integral from 0.5 to infinity of dx / x^2 = 2`. 2x oversampling: only `f > fs` folds, into `[0, fs]`, of which half is audible: `1 * 0.5 = 0.5`, ratio `0.5 / 2 = 0.25` = **-6.0 dB**. 4x: `f > 2 fs` (power `1 / 2`), a quarter audible: `0.5 * 0.25 = 0.125`, ratio `0.0625` = **-12.0 dB**. First-order ADAA at 1x: the integrand becomes `sin^2 (pi x) / (pi^2 x^4)`: on `[0.5, 1]` by Simpson with step 0.125 (values 1.621, 0.567, 0.160, 0.025, 0): `0.125 / 3 * (1.621 + 4 * 0.567 + 2 * 0.160 + 4 * 0.025 + 0) = 0.180`; on `[1, infinity)` with the mean `sin^2 = 0.5`: `0.5 / (3 pi^2) = 0.017`; sum `0.197`, ratio `0.197 / 2 = 0.098` = **-10.1 dB**. So first-order ADAA is worth more than 2x oversampling and less than 4x for edge-dominated spectra, at zero latency. For smooth laws (soft clip at low drive) the aliased power sits right above Nyquist, where `sinc^2` is only -3.9 dB (`f = 0.5 fs`) to -8.7 dB (`0.7 fs`): HYPOTHESIS 4 to 6 dB, with much less aliasing to start with.
**The price of ADAA in the pass band (derived).** In a linear stretch the two-tap average has the gain `cos (pi f / fs)`: -0.09 dB at 2 kHz, -0.56 dB at 5 kHz, -2.4 dB at 10 kHz, -6.4 dB at 15 kHz (44.1 kHz), on the wet signal only; at 2x it is `cos (pi f / (2 fs))`: -0.6 dB at 10 kHz, -1.3 dB at 15 kHz. The half-sample delay of the wet path against the dry path at mix 50 % costs `cos (pi f / fs)` of the sum again: -0.57 dB at 10 kHz.

### 3.2 The antiderivatives of the effect (the exact formulas the tasks implement)

Input `v = x * g` (`g = 10^(driveDb/20)`), `f` the law of `fx_effects.h:718-748`. Notation: `L (s) = log1p (exp (-2 s))` for `s >= 0` (`fast`: `0.69314718 * fastmath::log2 (1 + fastmath::exp (-2 s))`), `E (s) = 1 - exp (-s)`, `s = abs (v)`. Every kernel keeps two state values per channel, `vPrev` and `bPrev` (the bounded part of `F` at `vPrev`), so each sample costs one evaluation of the bounded part. `F` is split as `F = Lin + Bnd` with `Lin` piecewise linear (exact in float for neighbouring samples) and `Bnd` bounded by 0.7, because the plain difference `F (a) - F (b)` of two values near 30 loses `30 * 6e-8 = 1.8e-6` of absolute precision, which divided by `abs (a - b) = 1e-3` is `1.8e-3` = -55 dB; the split brings it to `0.7 * 6e-8 / 1e-3 = 4e-5` = -88 dB. Threshold `eps = 2^-10 = 9.77e-4` on `abs (a - b)`; below it `y = f ((a + b) / 2)` (error of the midpoint rule for tanh: `f'' dv^2 / 24 <= 0.77 * 9.5e-7 / 24 = 3e-8`; at a kink `dv / 8 = 1.2e-4` = -78 dB).

### 3.3 X-Shaper: the definition and the design

The behaviour is defined by the spec (1.1 B d); no owner decision is needed to implement it. What changes in sound against today: types 12 and 13 stop being a drive-scaled hard clip: with no curve drawn they become the clamped identity (`y = clamp (x, -1, 1)`, the drive no longer scales; `A150`: "the input is not scaled"), with curves they follow them. No factory preset uses them (1.1 B e), so no preset changes.
Data path: `ContentSet::build` samples `content.shaperA` and `content.shaperB` into 513-point tables with the curve law of `sampleCurve257` (`content_set.cpp:20-45`, `powerShape`, y clamped to 0..1) and, for each, the table of the cumulative integral; an empty (or one-point) curve is the identity `y[i] = i / 512`. `ContentSet` is immutable and handed over off the audio thread (`content_set.h:20-25`); the module reads it through `FxFrame::content` (`fx_module.h:34`, set at `own_engine.cpp:1511`), and `Distortion` gets plain pointers per call, never a vector.
Evaluation (audio thread, 512 segments, `h = 1 / 512`): for `u` in [0, 1], `s = 512 u`, `i = min (int s, 511)`, `t = s - i`: `c (u) = y[i] + (y[i+1] - y[i]) t`; `C (u) = I[i] + h (y[i] t + 0.5 (y[i+1] - y[i]) t^2)` with `I[i] = h * sum over k < i of (y[k] + y[k+1]) / 2` (double accumulation at build time). Outside: `u > 1: c = y[512]`, `C = C (1) + y[512] (u - 1)`; `u < 0: c = y[0]`, `C = y[0] u`. Morph with `m = clamp01 ((driveDb + 30) / 60)` (the `u` of `fx_effects.h:687`): `c = (1 - m) cA + m cB`, `C = (1 - m) CA + m CB` (linear, so exact). Type 12: `y = sign (x) c (min (abs x, 1))`, `F (x) = C (abs x)` (even; `integral from 0 to x of sign (t) c (abs t) dt = C (abs x)` for both signs of `x`, continued linearly beyond 1). Type 13: `u = (x + 1) / 2`, `y = 2 c (u) - 1`, `F (x) = 4 C (u) - 2 u` (`dt = 2 du`). ADAA of 3.0 on these is exact for the drawn piecewise-linear curve. Type 13 keeps the 10 Hz DC blocker (`fx_effects.h:749`).
Memory: `4 * 513 * 4 = 8.2 KB` per `ContentSet` that has a curve (none when both are empty).
