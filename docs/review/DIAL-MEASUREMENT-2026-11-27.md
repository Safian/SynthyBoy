Key architecture FACTs
- Every shipped native dial is a host `Knob` component with `knobType: FilmStrip`, `numFrames: 127`, square frames, strip = frame_size x (frame_size*127) (`components/native/level/level.py:26` FRAMES=127; `:417-431` `_strip_png/write_strip`; `:434-452` `synthyboy_dial_data`).
- The strip is ALREADY text-free. Caption (`name`) and value (`value`) are separate host `Label`/`Button` controls beside it (`level.py:507-608` compact_dial_definition, `:1031-1084` bare/stacked_dial_definition). Smooth is a text-free strip plus a caption Button/ActiveText toggle (`level.py:770-` build_native_smooth_dial_with_indicator_definition; caption pictures `smooth_caption_on/off.png` 50x24).
- The strip frame size is taken from the knob rect width (`level.py:561-608`, `rects["knob"][2]`), so any size can be generated by name `play_sub_{level|pan}_{N}.png` (`level.py:434-452`); `*_disabled.png` is a dimmed copy made on demand (`components/style.py:131-145` `_dim_artwork`).
- Today's sizes in components/sizes.json: `dial.diameter` 90 (line 10), `dial.compact.diameter` 40 (11), `smooth.knob.diameter` 60 (37), `smooth.width` 116 / height 72 (35-36), `dial.cell.height` 108 (12). The skin actually uses 40, 60, 64, 76, 90 (see part 2): 64 (FX cells) and 76 (Env) are literals in the extras scripts (`20_fx.py:320` `fx.native_dial.knob_size`, `96_env_native.py:193`), not in the sizes table.
