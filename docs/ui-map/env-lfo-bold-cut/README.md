# Env and LFO of the bold cut: before / after pictures

Owner decision 2026-11-21 ("Bold cut", the Env / Filter / LFO tab merges), steps 2 (Env) and 3 (LFO) of `docs/ui-map/env-filter-lfo-plan.md`; spec `docs/ui-map/SIMPLIFY.md` (C Env, D LFO, safe list K: U1 - U3, U11, U13, U14). Pictures: `scripts/render-ui-gallery.py` / `ui_gallery_host`, state Init, 1280 x 800, 16 Q-Link knobs (XL chips), quantised to 128 colours. `before/` = develop f6ae52d0 (steps 0 and 1 merged) before any change of these pages; `after/` = this branch. Nothing is removed from the engine or the parameter table: a control that is hidden comes back with the state that makes it apply, and every parameter is still reachable (`coverage_host`).

The page list is 16 pages now (22 before): Env 1 - 4 are ONE tab `Env`, LFO 1 - 4 are ONE tab `LFO` (the Filter merge is step 4, later). The kept views `env1` and `lfo1` keep their names and marker colours. The selection is the plugin's `Play Env` / `Play LFO` (+ the chunk-only `mpcTabView.rnd` for a random LFO): the same state as the Play page, saved in the chunk, nothing written to the engine by a choice.

## LFO (the recount)

`SIMPLIFY.md` estimated about 28 controls for the LFO; the recount of the picture says 17 before in the Hz state. Counted as controls: selector, shape picker, EDIT, TARGETS, RATE (or DIVISION), RISE, SMOOTH time, SMOOTH switch, HZ / BPM / KEY, PHASE, DELAY, MODE, HOST, DIRECTION, SWING, STEREO, MONO; the picker is ONE control (13 cells), the selector ONE control (14 cells).

| state | before | after | what changed |
|---|---|---|---|
| standard LFO, Hz, built-in shape | 17 always | 16 | EDIT hidden |
| standard, drawn shape | 17 | 17 | EDIT shown |
| standard, BPM (DIVISION instead of RATE, TRIP, DOT) | 19 | 18 | EDIT hidden |
| standard, drawn shape + BPM (the most) | 19 | 19 | - |
| standard, KEY (TRANSPOSE and TUNE instead of RATE) | 18 | 17 | EDIT hidden |
| random LFO, Hz (selector, style grid, RATE, HZ / BPM / KEY, STEREO toggle, trigger list, TARGETS) | 7 | 7 | - |
| random, BPM / KEY | 9 / 8 | 9 / 8 | - |
| Q groups, standard: RATE 4, TIMING 4, MOTION 4, SHAPE 1 (the SMOOTH switch); random: RANDOM 4, TRIGGER 1; KEY 2 only in KEY sync | 4 groups, SHAPE 2 (HOST, SMOOTH switch) | 4 groups, SHAPE 1 | HOST left the Q slots |

| control | before | after | where |
|---|---|---|---|
| instance cells | 14 fixed cells `1` .. `10`, `R1` .. `R4` (InstanceBar), the random LFO chosen in the page only | `UsedSelector`: the used LFOs and random LFOs, the selected one, then ONE `+`; `+` with two free kinds opens a two-row list (`LFO n` = the lowest free LFO, `RND m` = the lowest free random LFO), one kind selects at once; a chosen unused item is shown while selected and disappears when another is chosen; its parameters stay; shared with the Play page (`Play LFO` + `mpcTabView.rnd`) | `lfo_screen.h` `selector`, `lfo_ui.h` `adoptSelection`, `openPlusList` |
| `InstanceBar` | the component | deleted (U1 - U3 family) | `lfo_parts.h` |
| dead MONO `monoTop`, dead `style`, `shape`, `sync` steppers of the full screen | built, hidden for ever | deleted (U1, U2, U3); the compact view of the Play page keeps its live steppers | `lfo_screen.h` |
| HOST (`lfoN.host`) | under the shape picker, a Q member (group SHAPE, Q 13) | a touch-only toggle inside TIMING next to MODE (U14), no Q slot, like Master LINK; the TIMING group is frameless (HOST lies inside its union): the chips and the lit block mark it | `lfo_screen.h`; the coverage test treats `lfoN.host` as touch only |
| TIMING layout | list, PHASE over DELAY | the list, PHASE and DELAY side by side, MODE and HOST in the bottom row | `lfo_screen.h` |
| EDIT | shown for every shape; on a built-in shape it converted that shape into points | shown while the drawn shape is selected (bold cut); the DRAWN cell of the picker starts the points as the shape that was shown (square, sine ...), so nothing is lost | `lfo_screen.h` `setEditShown`, `lfo_ui.h` `ensureCustom` |

| TRIP, DOT; KEY TRANSPOSE, TUNE; random-irrelevant controls | already hidden (not dimmed) outside their mode | unchanged; tested by name per mode | `lfo_ui_host` `testLfoTab` |
| Q-Links | followed the LFO of the page | follow the selected LFO or random LFO | `qslots_host`, `lfo_ui_host` |
