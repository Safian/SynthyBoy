# FX pilot of the bold cut: before / after pictures

Owner decision 2026-11-21 ("Bold cut"), step 1 = the FX pilot; spec `docs/ui-map/SIMPLIFY.md` (section "Decided (owner 2026-11-21): bold cut", A). Pictures: `scripts/render-ui-gallery.py` / `ui_gallery_host`, state Init, 1280 x 800, 16 Q-Link knobs, quantised to 128 colours to keep the repository small.

- `before/` = the merged base (develop 26d9c4f0) BEFORE any FX code was changed: one picture per effect and per PAGE n / m (`_page1` .. `_page3`; the file without a suffix is the first page).
- `after/` = the default view (`Init_fx_<effect>.png`) and the MORE view (`Init_fx_<effect>_more.png`) of every effect kind; the three splitters have no MORE.
- The Init state hides what is not live (Distortion without a filter has nothing behind MORE; the Reverb has no room / feedback, the FX Filter no comb / formant values, the Delay is in Stereo style with the second time). The tests (`ui_fx_editor_host`, `testViews`) walk every state of the conditions of every table.

Cells = cells of the editor (a RATE / DIVISION pair is one cell; the power icon and the MORE button are not counted). "Cells before" is every cell of the old table (all pages, all live), "cells after" the cells of the default view with everything live (the most it can show; a control that is not live is hidden, so the real number in a state is lower).

Totals (13 pool effects): 174 cells before, 89 cells in the default views.

Notes
- Delay: the second time (TIME 2 / DIVISION 2) is in the default view only in a style that uses it. The engine reads it in Stereo, Ping pong, Mid ping pong and Tap->Delay; Mono ignores it (`core/engine-own/fx/fx_effects.h`, `Delay::process`: the right time of Mono is the left time), so in Mono it is hidden everywhere (it used to be shown always).
- Reverb: FORCE ON moved into the OUTPUT row (MORE) with LEVEL.
- Distortion: the filter cutoff and resonance are in the default view while the filter is on; the blend and the key track are MORE (also only with the filter on), so with no filter nothing is behind MORE.
- Compressor (second cut, review verdict): the default view must not show one band's numbers while the effect is Multiband. Default (8 cells): MIX, ATTACK, RELEASE, BANDS / MODE, THRESHOLD, RATIO of the SELECTED band and a BAND selector (LOW / MID / HIGH). The selector is view-local (a cell of the editor, not a parameter, no Q slot: it is the last cell of its row so the Q group MODE, THRESHOLD, RATIO stays on Q 1 .. 3; the display's marked band follows it) and is hidden in Single band; in Low band / High band mode the band that does not exist is disabled in it and the selection falls back to MID. THRESHOLD and RATIO are the UPPER pair of the band (the downward compression above the threshold; the lower pair is the upward stage, ratio 0 by default). In Limit mode the engine does not use the upper ratio (the limiter replaces the downward stage, `fx_compressor.h`), so RATIO is hidden there and the threshold is the ceiling. MODE is character-defining (Compress / Limit / Serum peak compressor change what the ratio does), so MODE stays in the default view and LEVEL goes behind MORE (the 8th cell is the selector). MORE (four rows, the display gives way): LEVEL, LATENCY COMP (Limit only), the crossovers, the three gains, the lower (upward) pairs of the three bands; the upper pair of a band that is not selected is one tap of the selector away (reachable, not duplicated).
