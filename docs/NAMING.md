# Naming: "SynthyBoy"

Owner decision (2026-11-04): the product is called **SynthyBoy**. "VST" is not part of the name (VST is a registered
trademark of Steinberg Media Technologies GmbH; only the factual compatibility statement is used). The GitHub repository was renamed accordingly: `Safian/SynthyBoyVST` → `Safian/SynthyBoy` (the old URL redirects).

## Rules

- Product / bundle / CLAP name: `SynthyBoy`. CLAP id: `com.safian.synthyboy`. VST3 bundle: `SynthyBoy.vst3`; CLAP bundle: `SynthyBoy.clap`.
- Do not use "Vital", "Vital Audio", "Tytel", "Matt Tytel" in the product name or marketing (upstream README). The factual
  statement "the engine is derived from Vital" is allowed in `NOTICE`/About.
- Do not use "VST" in the product name; do not use the VST3 logo.
- Avoid a Nintendo-flavoured presentation (no game-console iconography, no "Game Boy" wording) because of the `-Boy` suffix.

## Search done so far (2026-11-04)

This is **a first screening, not a trademark clearance**. The searches below were web searches (no access to the official
trademark registries from the automation environment).

| Where | Query | Result |
|-------|-------|--------|
| Web search (standard) | `"SynthyBoy" synthesizer plugin` | No product of that name. Nearest: **SynthBoy 64**, a free fantasy synth toy on itch.io ([luis-s.itch.io/synthboy-64](https://luis-s.itch.io/synthboy-64)); different spelling, different kind of product (toy/game, not a plugin). |
| Web search | `"Synthy Boy" OR "SynthyBoy"` + trademark/app/VST/KVR | No hit for the exact name on KVR or elsewhere. |
| Web search | `"Synthyboy"` + music software / audio plugin / iOS app | No hit. Nearest: the iOS app **Synthy** by Evan Escobar ([apps.apple.com/app/synthy/id6450637444](https://apps.apple.com/app/synthy/id6450637444)), a different name. |
| GitHub repository search | `synthyboy`, `synthy-boy` | Only this repository. |

Conclusion of the screening: no identical product name found; similar names exist (SynthBoy 64, Synthy). Absence of web hits
says nothing about registered trademarks.
